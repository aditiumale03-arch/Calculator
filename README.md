# 🧮 Advance Calculator

A professional and user-friendly calculator application built with **Python and Tkinter**.

Advance Calculator combines everyday calculations with scientific, mathematical, financial, health, and conversion tools in one clean and modern interface.

---

## ✨ Features

### 🔢 Standard Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculations
- Decimal calculations
- Large and easy-to-use buttons

### 🔬 Scientific Calculator

- Sin
- Cos
- Tan
- ASin
- ACos
- ATan
- Logarithm
- Natural logarithm (Ln)
- Square root
- Square (`x²`)
- Factorial (`!`)
- Powers (`^`)
- π constant
- e constant
- **Degree-based trigonometry by default**

### 📐 Mathematics

- Algebra solver
- Linear equations
- Quadratic equations
- Trigonometry tools

### 💰 Financial Analysis

Financial calculation tools designed to help with common financial calculations.

### ❤️ BMI Calculator

Calculate Body Mass Index (BMI) using height and weight.

### 🔄 Converters

Useful conversion tools for everyday calculations and measurements.

### 🕘 Calculation History

The calculator keeps track of previous calculations.

Features include:

- View previous calculations
- Standard calculator history
- Scientific calculator history
- Clear History
- Export History to a text file
- Newest calculations appear first

### 🌙 Light & Dark Mode

Switch between light and dark themes for a comfortable user experience.

### ☰ Navigation Menu

A three-line menu provides quick access to:

- Standard
- Scientific
- History
- Algebra
- Linear Equations
- Trigonometry
- Financial Analysis
- BMI
- Converters
- Help
- About
- Light/Dark Mode

The menu automatically closes after selecting an option.

---

Advance Calculator is designed with a professional and modern interface featuring:
